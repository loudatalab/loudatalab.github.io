PROYECTO 03 · SCOUTING · PYTHON

Football Manager Data Analysis

Procesado de datos de Football Manager con Python para analizar posibles fichajes o la plantilla actual, puntuando a cada jugador según los atributos que más importan en cada rol.

PythonPandasBeautifulSoupFootball Manager
ORIGEN DE LOS DATOSExportaciones HTML de FM
ENFOQUEScouting por roles
ESTADOFinalizado

Objetivo

Llevar al juego un proceso de scouting basado en datos: en lugar de revisar a los jugadores uno a uno, generar rankings por rol a partir de la lista de jugadores ojeados.

Metodología

  • Lectura de datos: la shortlist de jugadores ojeados se exporta desde Football Manager en HTML y se carga con Pandas.
  • Atributos parcialmente ojeados: cuando el juego muestra un rango (por ejemplo «12-15») se usa el valor medio como estimación.
  • Puntuaciones por rol: para cada rol (portero, portero líbero, carrilero…) se suma el valor de sus atributos clave y se ordena a los candidatos.
  • «ADN» del jugador: una puntuación transversal con agresividad, determinación, juego en equipo y sacrificio, para valorar la mentalidad independientemente de la posición.

Próximos pasos

Reorganizar el script en funciones reutilizables y construir una pequeña aplicación con interfaz para hacer el scouting directamente desde ella.
